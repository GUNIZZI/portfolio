화면 명세

  1. 1
    머리

    제목은 「HOW THIS SITE IS BUILT」이다. 제작 기간과 커밋 수는 집계 기준일의 수치를 사용한다. 저장소 링크는 새 탭에서 열린다.

  2. 2
    과정 한눈에 (컴포넌트 없음)

    순서 있는 목록이다. 단계마다 역할을 글자로 적는다. 단계를 누르면 이어지는 섹션으로 스크롤한다. 모바일에서는 위에서 아래로 쌓는다

  3. 3
    디자인

    단락 4개다. 시안은 그림 없이 글로만 설명한다. 레퍼런스로 삼은 사이트의 이름과 화면은 싣지 않는다

  4. 4
    Claude 가 개발

    5단계를 한 줄로 보이고 아래 표에서 대시보드를 예로 따라간다. 그림은 3줄까지만 그렸다. 기획 문서와 코드 폴더는 GitHub 저장소의 그 경로를 새 탭으로 연다. 기획 단계에는 기획 뷰어의 대시보드 와이어프레임을 새 탭으로 여는 링크도 둔다. 관리 화면으로는 링크를 걸지 않는다

  5. 5
    AI 가 틀리지 않게 한 장치

    장치마다 무엇을 막는지 한 줄과 실제로 걸리는 예 하나. 목록은 README.md 「AI 가 틀리지 않게 한 장치」 표

  6. 6
    사람이 한 일

    문서의 「사용자 결정」 기록을 근거로 쓴다

  7. 7
    기술과 구조 (컴포넌트 없음)

    글은 앞의 섹션보다 짧다. 기술은 이름만 적는다. 구조 그림은 순서 있는 목록이고 화살표만 SVG 다. 그림의 모양은 구현할 때 사용자가 확인한다. 폰트는 이름과 라이선스를 적는다
