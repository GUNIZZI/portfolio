# 이 사이트는 이렇게 (`/colophon`) — 기획

이 포트폴리오를 어떻게 만들었는지 보여 주는 페이지다. 기술 선택과 구조, AI 와 함께 만드는 개발 환경(AX)을 담는다.

**초안이다.** 사용자가 아직 채택하지 않은 페이지를 제안으로 채운 문서다.(`../README.md` 3.2)
모든 기획안이 `제안` 이고, 채택하면 [검토 필요 사항](#검토-필요-사항)에서 하나씩 확정한다.

## 정책(제안)

### 구성

| 순서 | 섹션    | 내용                                                                    | 근거가 되는 파일                            |
| ---- | ------- | ----------------------------------------------------------------------- | ------------------------------------------- |
| 1    | 머리    | 한 줄 요약과 저장소 링크                                                | —                                           |
| 2    | 기술    | Next.js 16 · React 19 · TypeScript · Tailwind v4 · framer-motion · GSAP | `package.json`                              |
| 3    | 구조    | 계층과 의존 방향 그림. ESLint 가 경계를 검사한다                        | `docs/architecture.md`, `eslint.config.mjs` |
| 4    | AX 환경 | CLAUDE.md · 규칙 문서 · 훅 3개 · 스킬 · 에이전트, 각각이 막는 실수      | `CLAUDE.md`, `.claude/`                     |
| 5    | 디자인  | 디자인 원본과 토큰, 폰트와 라이선스                                     | `docs/design.md`                            |
| 6    | 기획    | 이 기획 체계와 뷰어                                                     | `docs/plan/`                                |

- 내용은 저장소의 실제 코드와 문서를 근거로 쓴다. 숫자(문서 수, 테스트 수)는 쓰는 시점에 센다.
- 훅은 "무엇을 막는가" 를 예시와 함께 보여 준다. 예: `duration: 0.6` 을 쓰면 토큰을 쓰라고 알린다.
