# 찾을 수 없음 (404) — 기획

없는 주소로 들어왔을 때 보이는 페이지다. 홈과 작업 목록으로 가는 버튼을 둔다.

**초안이다.** 사용자가 아직 채택하지 않은 페이지를 제안으로 채운 문서다.(`../README.md` 3.2)
모든 기획안이 `제안` 이고, 채택하면 [검토 필요 사항](#검토-필요-사항)에서 하나씩 확정한다.

| [wireframe.html](./wireframe.html) | 와이어프레임과 화면 설계 명세. 브라우저로 연다 |

## 요구사항

아직 없다. 작업 상세 초안이 없는 `slug` 를 이 페이지로 보낸다.([work/](../work/README.md))

## 페이지 위치

| 항목        | 값                                   |
| ----------- | ------------------------------------ |
| 구역        | 공통                                 |
| 페이지명    | 찾을 수 없음                         |
| 라우트      | 없는 모든 주소 (`app/not-found.tsx`) |
| 들어오는 곳 | 잘못된 주소, 없는 작업 `slug`        |

## 정책(제안)

- 캐릭터 일러스트와 마커 제목 「Oops! Lost?」, 한 줄 안내를 둔다.
- 버튼은 2개다. 홈으로(`/`) · 작업 보기(`/work`, 작업 목록이 없으면 `/#projects`).
- 헤더와 푸터는 다른 페이지와 같다. 메뉴로도 돌아갈 수 있게 하기 위해서다.
- 캐릭터는 새로 그린 그림이 필요하다. 없으면 브이 캐릭터(`characters/peace.png`)를 쓴다.

## 모션(제안)

| 요소   | 계기         | 연출           | 도구          | 토큰            | 동작 줄이기   |
| ------ | ------------ | -------------- | ------------- | --------------- | ------------- |
| 캐릭터 | 처음 그릴 때 | 한 번 갸웃한다 | framer-motion | `SPRING.follow` | 움직이지 않음 |

## 기능 정의

| ID   | 기능            | 화면 | 설명    |
| ---- | --------------- | ---- | ------- |
| F-01 | 홈으로(제안)    | S-01 | `/`     |
| F-02 | 작업 보기(제안) | S-01 | `/work` |

## 접근성 · 성능 고려

- 페이지 제목(`title`)에 「찾을 수 없음」 을 넣는다.
- 응답 상태는 404 다. Next 의 `notFound()` 와 `not-found.tsx` 가 정한다.
