# 로그인 (`/admin` · `/admin/login`) — 기획

관리 화면에 들어오는 곳이다. 관리자 1명이 이메일과 비밀번호로 로그인하고, 로그인한 동안만 관리 화면을 볼 수 있다.

이 문서는 **이미 있는 화면에 새 동작을 더하는 기획**이다.(`../../README.md` 3.1)
로그인 화면 · 세션 · 로그아웃은 코드에 있다. 표시 없이 적는다.(`src/features/adminAuth/` · `src/entities/session/`)
`/admin` 의 동작과 로그인한 뒤에 가는 곳(요구사항 5 · 6 · 8번)도 구현했다(2026-11-17). 대시보드 · 프로젝트 · 소개 · 경력은 아직 제목만 있는 화면이다.

## 요구사항

사용자가 정한 요구사항이다.

1. **로그인은 Firebase Auth 를 쓰고, 관리자 계정은 Firebase Auth 에 등록해서 쓴다.**(2026-11-12)
2. **로그인은 이메일과 비밀번호로 한다. 세션은 2시간 동안 유지한다.**(2026-11-17)
3. **비밀번호는 서버에서 확인한다. 관리자는 `ADMIN_UID` 환경 변수와 UID 가 같은 계정 1개다.**(2026-11-17)
4. **로그인 · 로그아웃 버튼에는 버튼의 연출을 두지 않는다.**(2026-11-17)
5. **`/admin` 과 `/admin/login` 이 로그인이다.**(2026-11-17)
6. **프로젝트 목록의 주소는 `/admin/projects` 다.**(2026-11-17)
7. **로그인의 기획은 프로젝트 관리 기획과 따로 둔다.**(2026-11-17)
8. **로그인한 뒤의 첫 화면은 대시보드다.**(2026-11-17)
9. **이 문서에 `제안` 으로 적었던 기획안을 모두 채택한다.**(2026-11-17)

1~3번은 [프로젝트 관리 기획](../README.md)의 요구사항 9 · 13 · 14번에서 옮겼다.

## 정책

### 접근

- `/admin` 아래의 모든 화면은 로그인한 관리자만 볼 수 있다. 서버에서 세션을 검사한다.
- 로그인하지 않고 들어오면 [S-01 로그인](./wireframe.html#s01)으로 보낸다. 들어오려던 주소는 기억하지 않는다.(`src/proxy.ts`)
- 검사는 2번 한다. 쿠키가 없으면 페이지를 그리기 전에 보내고, 쿠키가 있으면 페이지가 값을 검증한다.(`docs/architecture.md` 4.2절)
- 관리 화면은 검색 색인에서 뺀다.(`src/app/admin/layout.tsx`)

### 로그인

- 로그인은 Firebase Auth 로 한다.(요구사항 1)
- 관리자 계정은 Firebase 콘솔에서 Firebase Auth 에 등록한 계정 1개다. 가입과 비밀번호 찾기는 두지 않는다.
- 이메일과 비밀번호로 로그인한다.(요구사항 2) 2개를 모두 입력해야 로그인 버튼을 누를 수 있다.
- 비밀번호는 서버가 Firebase Auth 에 확인한다. 브라우저에는 Firebase SDK 를 싣지 않는다.(요구사항 3)
- Firebase Auth 에 있는 계정이어도 UID 가 `ADMIN_UID` 와 다르면 관리자가 아니다.(요구사항 3) 이메일 · 비밀번호 로그인을 켜면 누구나 Firebase Auth 에 계정을 만들 수 있기 때문이다.
- 로그인하는 동안 버튼은 비활성이고 문구가 「로그인하는 중」 으로 바뀐다.(`src/features/adminAuth/ui/LoginForm.tsx`)
- 로그인하면 [대시보드](../dashboard/README.md)(`/admin/dashboard`)로 간다.(요구사항 8)
- 이미 로그인한 채 로그인 화면에 들어오면 대시보드로 보낸다.

### 로그인하지 못했을 때

- 거절과 실패 모두 세션을 만들지 않고 안내 상자를 보여 준다. 입력한 값은 그대로 둔다.
- 거절일 때는 이메일과 비밀번호 중 무엇이 틀렸는지 알리지 않는다. 관리자가 아닌 계정으로 로그인한 것도 거절이다.
- 문구는 [S-02 로그인 상태](./wireframe.html#s02)에 있다.
- **실패의 문구는 「로그인하지 못했습니다 · 잠시 후 다시 시도해 주세요.」 다.** 코드에 들어 있지만 사용자가 정한 문구가 아니다.(`src/features/adminAuth/model/adminAuth.constants.ts`)

### 세션 · 로그아웃

- 세션은 2시간 동안 유지한다.(요구사항 2) 쓰는 동안에도 늘어나지 않는다. 로그인한 때부터 2시간이다.(`src/entities/session/model/session.constants.ts`)
- 세션 쿠키는 스크립트가 읽지 못하는 쿠키다(`httpOnly`).
- 로그아웃은 프로젝트 목록의 로그아웃 버튼으로 한다. 세션 쿠키를 지우고 로그인 화면으로 간다.
- 로그아웃은 브라우저의 쿠키만 지운다. Firebase 에 발급된 세션을 폐기하지는 않는다.(`src/entities/session/actions/session.actions.ts`)
- 세션이 끝난 뒤 관리 화면을 열거나 저장을 누르면 로그인 화면으로 보낸다. 입력하던 내용은 남지 않는다.

### `/admin`

- **`/admin` 은 화면을 따로 그리지 않고 보내기만 한다.** 세션이 없으면 `/admin/login`, 있으면 `/admin/dashboard` 로 보낸다. 로그인 화면의 주소를 하나로 두기 위해서다.(`src/features/adminAuth/ui/AdminEntry.tsx`)

## 모션

연출을 두지 않는다. 로그인 · 로그아웃 버튼은 hover 와 포커스에서 색만 짧게 바뀐다.(요구사항 4, `src/shared/ui/button/button.md` 「연출 없이 쓰기」)

## 반응형

화면 가운데에 폭이 고정된 상자 하나를 둔다. 좁은 화면에서는 좌우 여백만 줄어든다.(`src/features/adminAuth/ui/AdminLogin.tsx`)

## 기능 정의

| ID   | 기능              | 화면        | 설명                                                                 |
| ---- | ----------------- | ----------- | -------------------------------------------------------------------- |
| F-01 | 로그인            | S-01 · S-02 | Firebase Auth 에 등록한 관리자 계정으로 로그인한다                   |

| F-04 | 사이트로 돌아가기 | S-01        | 로고나 링크로 공개 화면의 홈에 간다                                  |

## 데이터

로그인 상태는 entity `session` 이 다룬다. 저장소는 Firebase Auth 다.(`src/entities/session/README.md`)

| 항목        | 내용                                                                    |
| ----------- | ----------------------------------------------------------------------- |
| 관리자 계정 | Firebase Auth 의 이메일 · 비밀번호 계정 1개. Firebase 콘솔에서 등록한다 |
| 세션 쿠키   | 이름은 `admin_session`. Firebase 가 서명한 값이고 2시간 뒤에 끝난다     |
| 환경 변수   | 5개. 이름과 검증은 `src/shared/util/serverEnv.ts` 에 있다               |

| 동작      | 경로                                                                                 |
| --------- | ------------------------------------------------------------------------------------ |
| 로그인    | 폼 → `session.actions` → `session.services` → `session.repositories` → Firebase Auth |
| 세션 검사 | `src/proxy.ts`(쿠키 유무) → `AdminGuard` → `session.services` → Firebase Admin       |
| 로그아웃  | 버튼 → `session.actions`                                                             |

## 접근성 · 성능 고려

- 이메일과 비밀번호에 `label` 을 잇는다.(`src/shared/ui/input/input.md`)
- 안내 상자는 `role="status"` 로 알린다. 문구가 없을 때도 요소를 둔다. 나중에 생긴 `role="status"` 는 스크린 리더가 읽지 않는다.(`src/features/adminAuth/ui/LoginForm.tsx`)
- 이메일에는 `autocomplete="username"`, 비밀번호에는 `autocomplete="current-password"` 를 단다. 비밀번호 관리 도구가 채울 수 있다.
- 로그인 화면에는 공개 화면의 헤더 · 푸터 · 배경을 싣지 않는다.
