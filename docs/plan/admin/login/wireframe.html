로그인 (/admin · /admin/login)

관리자는 이메일과 비밀번호로 관리 화면에 로그인한다. 사용 계정은 1개다.

구현된 로그인 화면의 배치와 입력 순서, 상태별 동작을 보여 준다. 정책은 README.md에, 사용자 흐름은 userflow.md에 정리했다. 프로젝트 목록의 로그아웃 버튼은 프로젝트 관리 와이어프레임(../wireframe.html)에서 확인할 수 있다.
