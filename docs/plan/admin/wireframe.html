작업 관리 (/admin)

포트폴리오에 싣는 작업을 등록 · 수정 · 삭제하고 공개 여부와 순서를 정하는 관리 화면의 와이어프레임이다. 관리자 1명만 들어온다.

관리 화면은 디자인 원본이 없다. 여기서는 배치 · 순서 · 상태만 그리고, 모양은 지금의 토큰으로 표와 폼을 단순하게 그린다(제안). 정책과 입력 규칙은 README.md, 흐름은 userflow.md 가 갖는다.
