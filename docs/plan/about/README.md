# 소개 (`/about`) — 기획

GUNI 가 어떤 개발자인지 홈보다 자세히 보여 주는 페이지다. 경력 · 일하는 방식 · 기술을 담는다.

**초안이다.** 사용자가 아직 채택하지 않은 페이지를 제안으로 채운 문서다.(`../README.md` 3.2)
모든 기획안이 `제안` 이고, 채택하면 [검토 필요 사항](#검토-필요-사항)에서 하나씩 확정한다.

## 요구사항

아직 없다. 홈 기획의 검토 필요 사항 5번(소개 연결)이 이 페이지를 가리킨다.([home/](../home/README.md))

## 페이지 위치

| 항목        | 값                                     |
| ----------- | -------------------------------------- |
| 구역        | 소개                                   |
| 페이지명    | 소개                                   |
| 라우트      | `/about`                               |
| 들어오는 곳 | 홈의 More About Me, 헤더의 About(제안) |

## 용어

| 용어          | 뜻                                                   |
| ------------- | ---------------------------------------------------- |
| 경력 타임라인 | 회사 · 기간 · 역할 · 한 일을 시간 순서로 나열한 목록 |
| 일하는 방식   | 협업과 개발에서 지키는 원칙 몇 가지                  |

## 정책(제안)

### 구성

| 순서 | 섹션          | 내용                                                                            |
| ---- | ------------- | ------------------------------------------------------------------------------- |
| 1    | 인트로        | 큰 캐릭터 일러스트, 소개 문단, 이력서 버튼                                      |
| 2    | 경력 타임라인 | 최신부터. 회사 · 기간 · 역할 · 한 일 2~3줄                                      |
| 3    | 일하는 방식   | 3가지. 예: 규칙과 도구를 먼저 세운다 · 움직임에 이유를 둔다 · AI 와 함께 만든다 |
| 4    | 기술          | 분야별 묶음(화면 · 상태 · 스타일 · 움직임 · 품질 · 협업)                        |
| 5    | 연락          | 홈의 연락 섹션과 같은 부품                                                      |

- 타임라인은 순서가 있는 정보라 연도를 앞에 둔다.
- 기술 묶음은 홈의 기술 타일보다 자세히 쓴다. 어디에 썼는지 한 줄씩 붙인다.

## 모션(제안)

| 요소        | 계기          | 연출                         | 도구          | 토큰                           | 동작 줄이기  |
| ----------- | ------------- | ---------------------------- | ------------- | ------------------------------ | ------------ |
| 타임라인 선 | 스크롤        | 스크롤만큼 세로선이 그려진다 | framer-motion | `useScroll`                    | 다 그려진 선 |
| 경력 항목   | 화면에 들어옴 | 한 번 올라온다               | framer-motion | `DURATION.base` · `EASE.enter` | 보이는 상태  |

## 반응형

| 화면 폭 | 배치                                                   |
| ------- | ------------------------------------------------------ |
| 넓음    | 인트로 좌우(글 · 캐릭터), 타임라인은 연도 열 + 내용 열 |
| 모바일  | 캐릭터가 글 위로, 타임라인은 한 열                     |

## 기능 정의

| ID   | 기능                  | 화면 | 설명                  |
| ---- | --------------------- | ---- | --------------------- |
| F-01 | 소개 읽기(제안)       | S-01 | 인트로 · 일하는 방식  |
| F-02 | 경력 보기(제안)       | S-01 | 타임라인              |
| F-03 | 이력서 내려받기(제안) | S-01 | 홈과 같은 PDF         |
| F-04 | 연락하기(제안)        | S-01 | 홈의 연락 섹션과 같다 |

## 데이터(제안)

`content/about.ts` 에 둔다. 읽는 곳은 새 entity `experience` 다.

| 항목         | 내용                          |
| ------------ | ----------------------------- |
| `company`    | 회사                          |
| `period`     | 기간. 표시는 `2025.03 – 현재` |
| `role`       | 역할                          |
| `highlights` | 한 일 2~3줄                   |

## 접근성 · 성능 고려

- 타임라인은 `ol` 이다. 순서에 의미가 있다.
- 큰 캐릭터 이미지는 화면 폭에 맞는 크기로 내린다.

| No  | 항목                 | 기획안                                   | 확인 대상          |
| --- | -------------------- | ---------------------------------------- | ------------------ |

| 3   | 일하는 방식 3가지    | 정책의 예시                              | 사용자             |

| 7   | 데이터 위치          | `content/about.ts` + entity `experience` | 사용자             |
