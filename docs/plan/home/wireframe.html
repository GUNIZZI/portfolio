화면 명세

  1. 1
    Header widgets/header

    메뉴 3개(Home · Projects · About)는 각 페이지로 간다. 지금 있는 페이지의 메뉴에 밑줄. Contact 버튼 → #contact. 그 오른쪽의 테마 버튼(ThemeToggle shared/ui/themeToggle)으로 다크와 라이트를 바꾼다. 테마 버튼 오른쪽의 자물쇠 버튼 → /admin. 처음 방문은 다크이고, 정책은 README 「테마」

  2. 2
    Hero features/hero

    이름은 h1. 등장 연출은 S-04, 값은 README 「모션」 표

  3. 3
    Button shared/ui/button

    View My Projects → #projects. 이력서 버튼은 두지 않는다

  4. 4
    HeroVisual

    캐릭터는 처음 화면 이미지라 미리 불러온다(loading="eager"). 손글씨는 aria-hidden. 낙서는 포인터 반대쪽으로 밀린다

  5. 5
    FeaturedProjects · ProjectCard

    카드는 content/projects.ts 순서. 카드 어디를 눌러도 /project/<slug>. View All Projects → /project

  6. 6
    Skills

    타일 14개. hover 때 아이콘이 흔들린다

  7. 7
    About

    숫자 3개는 원본 값이고 나중에 바꾼다. More About Me → /about

  8. 8
    Contact

    버튼은 Get in Touch 1개 → mailto:. 마우스 오버 · 초점 때 문구가 메일 주소로 바뀐다.

  9. 9
    Footer widgets/footer

    GitHub 는 프로필 주소로 새 탭. 메뉴는 Home · Projects · About · Contact

  10. 10
    ColophonTeaser features/colophon

    소개와 연락 사이에 둔다. 4단계와 역할은 콜로폰 페이지의 「과정 한눈에」 와 같은 값이고 누를 수 없다. See How It's Built → /colophon. 4단계는 화면에 처음 들어올 때 왼쪽부터 하나씩 나타난다. 값은 README 「모션」 표. 버튼은 shared/ui/button. 정책은 README 「제작 과정 섹션」

화면 명세

  1. 1
    메뉴 버튼

    닫혀 있으면 ☰, 열려 있으면 ✕. aria-expanded · aria-controls. 이름은 「메뉴 열기」 · 「메뉴 닫기」. 아이콘은 shared/ui/icon 의 menu · close

  2. 2
    패널

    헤더 바로 아래에서 화면 끝까지 덮는다. 메뉴 3개를 세로로. 지금 있는 페이지(여기서는 Home)에 강조색. 바탕 glass, 층 z-overlay. 메뉴 항목을 누르면 닫고 그 페이지로 간다

  3. 3
    Button shared/ui/button

    Contact → #contact. 좁은 화면에서는 헤더가 아니라 여기에 둔다

  4. 4
    뒤의 화면

    패널의 반투명 바탕 너머로 흐리게 비친다. 스크롤은 잠그지 않는다. Esc 로 닫히고 초점은 메뉴 버튼으로 돌아간다
