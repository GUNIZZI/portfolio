# 홈 (`/`) — 기획

사이트의 첫 화면이다. GUNI 를 소개하고, 작업 보기와 연락으로 이어 준다.

이 문서는 **이미 있는 페이지에 새 동작을 더하는 기획**이다.(`../README.md` 3.1)
섹션 구성 · 문구 · 배치는 코드에 있고 디자인 원본(`sample/HYOSUNG 포트폴리오.html`)과 같다. 표시 없이 적는다.
링크 연결 · 모션 · 상태처럼 아직 없는 동작은 요구사항에 없어 `제안` 으로 채웠다. [검토 필요 사항](#검토-필요-사항)에서 확정한다.

## 요구사항

사용자가 정한 요구사항이다.

1. **디자인은 `sample/HYOSUNG 포트폴리오.html` 을 따른다.**(2026-11-12)
2. **이름은 GUNI 로 쓴다.**(2026-11-12)
3. **연락 메일은 `h2dlhs@naver.com` 이다.**(2026-11-12)
4. **블로그와 유튜브 링크는 두지 않는다.**(2026-11-12)
5. **인터랙션과 모션은 정적 화면을 맞춘 다음 단계에서 붙인다.**(2026-11-11)

## 정책

### 섹션 구성

코드에 있는 순서다.(`src/app/page.tsx`)

| 순서 | 섹션      | id         | 담당                        |
| ---- | --------- | ---------- | --------------------------- |
| 1    | 헤더      | —          | `widgets/header`            |
| 2    | 히어로    | —          | `features/hero`             |
| 3    | 대표 작업 | `projects` | `features/featuredProjects` |
| 4    | 기술      | `skills`   | `features/skills`           |
| 5    | 소개      | `about`    | `features/about`            |
| 6    | 연락      | `contact`  | `features/contact`          |
| 7    | 푸터      | —          | `widgets/footer`            |

페이지 맨 위는 `#top` 이다. 로고와 헤더의 Home 이 이곳을 가리킨다.

### 메뉴

- 헤더 메뉴는 Home · About · Projects · Skills · Contact 다. 같은 페이지 안의 섹션으로 이동한다.(`src/config/nav.ts`)
- 푸터 메뉴는 Skills 를 뺀 4개다.
- **현재 메뉴 표시(제안)**: 화면 가운데에 걸친 섹션의 메뉴에 밑줄과 강조색을 준다. 지금은 Home 에 고정이다.
- **헤더 고정(제안)**: 히어로를 지나 스크롤하면 헤더를 화면 위에 붙이고 바탕을 반투명으로 흐린다. 위로 돌아오면 원래 위치로 돌아간다.

### 링크 연결(제안)

지금 임시 주소를 가리키는 링크의 목적지다.

| 요소                    | 지금        | 목적지(제안)                    | 필요한 것                                    |
| ----------------------- | ----------- | ------------------------------- | -------------------------------------------- |
| Download Resume         | `#top`      | `/resume.pdf` 를 새 탭으로 연다 | 이력서 PDF 파일                              |
| View All Projects       | `#projects` | `/work`                         | 작업 목록 페이지([work/](../work/README.md)) |
| 작업 카드의 열기 아이콘 | `#projects` | `/work/<id>`                    | 작업 상세 페이지                             |
| More About Me           | `#about`    | `/about`                        | 소개 페이지([about/](../about/README.md))    |
| GitHub · LinkedIn       | `#top`      | 각 프로필 주소, 새 탭           | 주소                                         |

외부 링크는 `target="_blank"` 와 `rel="noopener noreferrer"` 를 붙인다.

### 이메일(제안)

- `Get in Touch` 버튼은 `mailto:` 로 메일 앱을 연다. 지금과 같다.
- 메일 주소 버튼은 누르면 주소를 클립보드에 복사하고 [P-01 복사됨 토스트](./wireframe.html#p01)를 띄운다. 메일 앱이 없는 환경에서도 주소를 가져갈 수 있게 하기 위해서다.
- 클립보드에 쓸 수 없으면 `mailto:` 로 대신 연다.

### 임시 값

- 소개 섹션의 숫자 3개는 원본 값이다. 사용자가 나중에 바꾼다.(`src/features/about/model/about.constants.ts`)
- 4번째 작업 카드는 썸네일이 없어 임시 이미지를 표시한다.(`content/projects.ts`)

## 모션(제안)

요구사항 5번에 따라 다음 단계에서 붙인다. 낙서 디자인이라 **선이 그려지는** 연출을 공통으로 쓴다.
페이지를 처음 그릴 때 실행하는 연출은 히어로에만 둔다. 나머지는 스크롤하거나 방문자가 조작할 때 실행한다.

| 요소             | 계기               | 연출                                 | 도구          | 토큰                             | 동작 줄이기    |
| ---------------- | ------------------ | ------------------------------------ | ------------- | -------------------------------- | -------------- |
| 히어로 낙서      | 처음 그릴 때 한 번 | 왕관 · 밑줄 · 번개가 선으로 그려진다 | framer-motion | `DURATION.slow` · `EASE.enter`   | 다 그려진 상태 |
| 히어로 이름      | 처음 그릴 때 한 번 | 마커로 칠하듯 왼쪽부터 드러난다      | framer-motion | `DURATION.slower` · `EASE.enter` | 보이는 상태    |
| 말풍선           | 처음 그릴 때 한 번 | 이름 다음에 튀어나온다               | framer-motion | `SPRING.follow`                  | 보이는 상태    |
| 히어로 낙서      | 포인터 이동        | 포인터 반대쪽으로 살짝 밀린다        | framer-motion | `SPRING.follow`                  | 움직이지 않음  |
| 헤더             | 히어로를 지남      | 위에 붙고 바탕이 흐려진다            | framer-motion | `DURATION.base` · `EASE.move`    | 바로 붙음      |
| 작업 카드        | 화면에 처음 들어옴 | 아래에서 차례로 올라온다(한 번만)    | framer-motion | `DURATION.base` · `STAGGER.base` | 보이는 상태    |
| 작업 카드        | hover · focus      | 살짝 떠오르고 썸네일이 커진다        | CSS           | `duration-fast` · `ease-move`    | 색만 바뀜      |
| 기술 타일        | hover · focus      | 아이콘이 한 번 흔들린다              | CSS           | `duration-fast`                  | 움직이지 않음  |
| 소개 숫자        | 화면에 처음 들어옴 | 0 부터 세어 올라간다                 | framer-motion | `DURATION.slower`                | 최종 숫자      |
| 섹션 제목 밑줄   | 화면에 처음 들어옴 | 선으로 그려진다                      | framer-motion | `DURATION.slow` · `EASE.enter`   | 다 그려진 상태 |
| 가장자리 붓 자국 | 스크롤             | 스크롤보다 느리게 움직인다           | GSAP          | ScrollTrigger scrub              | 움직이지 않음  |

- 무한 반복하는 연출은 두지 않는다.(`docs/motion.md` 금지사항, WCAG 2.2.2)
- 한 요소에 도구 2개를 함께 쓰지 않는다.(`docs/motion.md` 1절)

## 반응형

코드에 있는 배치다. 섹션마다 `flex-wrap` 으로 줄이 바뀐다.
경계 폭은 고정 값이 아니다. 각 영역의 기준 폭을 더한 값이 경계가 된다. 히어로는 글 440px + 캐릭터 380px + 간격과 여백이다.(`src/features/hero/ui/Hero.tsx`)

| 화면 폭              | 배치                                                   |
| -------------------- | ------------------------------------------------------ |
| 넓음 (약 920px 이상) | 히어로 글과 캐릭터가 좌우, 소개의 3개 영역이 한 줄     |
| 좁음 (약 920px 미만) | 히어로 캐릭터가 글 아래로, 소개 · 연락이 세로로 쌓인다 |
| 모바일 (390px)       | 헤더 메뉴가 로고 아래 한 줄, 작업 카드 한 열           |

## 접근성 · 성능 고려

- 손글씨 장식 문구(말풍선, `Ideas Design…`, `Let's Build…`, `Good Ideas…`)는 `aria-hidden` 이다. 같은 뜻이 본문에 있다.
- 아이콘만 있는 링크(작업 열기, 외부 프로필)에는 `aria-label` 이 있다.
- 히어로 이미지 원본은 1.1MB PNG 다. **WebP 로 바꾸고 화면 폭에 맞는 크기로 내린다(제안).**
- 등장 연출이 레이아웃을 밀지 않게 한다. 목표는 CLS 0, Lighthouse 성능 90 이상이다(제안).
- 복사됨 토스트는 `role="status"` 로 스크린 리더에 알린다(제안).
