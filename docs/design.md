# 디자인 방향

화면 디자인의 기준을 정하는 문서다. 토큰 값의 근거를 이 문서에 적는다.

**디자인 원본은 `sample/HYOSUNG 포트폴리오.html` 이다.** 외부에서 만들어 가져온 반응형 페이지 1개이고,
2026-11-12 에 사용자가 이 디자인으로 정했다. 형광 마커와 손글씨, 낙서, 캐릭터 일러스트로 이루어진다.
화면이 원본과 다르면 원본을 따른다. 의도해서 바꾼 것은 4절에 적는다.

## 원칙

근거는 모두 원본 파일과 2026-11-12 사용자 결정이다.

1. **원본의 값을 토큰으로 옮긴다.** 색·글자 크기·모서리를 원본에서 그대로 가져와 `src/style/tokens/` 에 이름을 붙인다.
2. **낙서의 위치는 원본의 백분율을 그대로 쓴다.** 캐릭터 주변의 왕관·번개·말풍선은 그림 크기에 맞춰 함께 움직인다.
3. **모션은 정적 화면을 맞춘 다음에 붙인다.** 홈은 붙였다. 목록은 `docs/plan/home/README.md` 「모션」 표다.

## 1. 색

토큰 파일: `src/style/tokens/color.css`. 다크 전용이다.

| 토큰                         | 값        | 쓰는 곳                      |
| ---------------------------- | --------- | ---------------------------- |
| `background`                 | `#0a0a12` | 페이지 바탕                  |
| `panel`                      | `#10101a` | 작업·소개를 묶는 큰 면       |
| `card`                       | `#161624` | 작업 카드, 기술 타일         |
| `chip`                       | `#181826` | 히어로 기술 태그             |
| `panel-glass`                | 알파 0.5  | 작업·소개를 묶는 반투명 패널 |
| `glass`                      | 알파 0.8  | 화면 위에 붙은 헤더의 바탕   |
| `strong`                     | `#f4f4f5` | 제목, 링크                   |
| `foreground`                 | `#d4d4d8` | 본문                         |
| `muted`                      | `#a1a1aa` | 보조 설명                    |
| `accent`                     | `#a3e635` | 주 버튼, 현재 메뉴, 밑줄     |
| `brand`                      | `#9333ea` | 헤더 Contact 버튼, 소개 밑줄 |
| `doodle-*`                   | 5색       | 왕관·번개·별·말풍선·로고     |
| `brush-sky` · `brush-violet` | 알파 0.85 | 가장자리 붓 자국             |

바탕 대비는 `strong` 17.9 · `foreground` 13.3 · `muted` 7.7 · `accent` 13.1 이다. 모두 WCAG AA(4.5)를 넘는다.
`decorative`(`#71717a`)는 4.1 이라 정보 전달에 쓰지 않는다.
버튼 글자 대비는 `accent` 위 13.1, `brand` 위 흰 글자 5.4 다.

## 2. 글자

토큰 파일: `src/style/tokens/typography.css`

| 폰트             | 토큰          | 쓰는 곳                  |
| ---------------- | ------------- | ------------------------ |
| Permanent Marker | `font-marker` | 이름, 직함, 섹션 제목    |
| Caveat           | `font-hand`   | Hey, 말풍선, 손글씨 메모 |
| Noto Sans KR     | `font-sans`   | 그 밖 전부               |

원본 파일에는 Noto Sans KR 이 들어 있지 않아 macOS 에서는 시스템 폰트로 보인다.
구현은 원본이 지정한 Noto Sans KR 을 실제로 불러온다. 한글 굵기가 원본 화면과 조금 다른 이유다.

`clamp()` 로 커지는 크기는 `text-hero` · `text-section` 처럼 이름을 붙였다. 값은 원본 그대로다.

## 3. 배치

```
헤더      로고 · 메뉴 4개 · Contact 버튼
히어로    Hey, I'm / GUNI / Frontend Developer / 태그 / 버튼 1개   ←→ 캐릭터와 낙서
패널      FEATURED PROJECTS(카드 격자) + MY SKILLS(타일 격자)
소개      캐릭터 · ABOUT ME · 숫자 3개
연락      Get in Touch! · 버튼 1개 · 손글씨와 브이 캐릭터
푸터      로고 · 외부 링크 · 메뉴 · 저작권
```

- 페이지 폭은 `max-w-page`(1240px), 좌우 여백은 `px-gutter`(16–40px)다.
- 좁은 화면에서는 `flex-wrap` 으로 히어로·소개·연락이 세로로 쌓인다. 원본과 같다.

## 미정리 항목

- 소개 섹션의 숫자 3개(40+ · 20+ · 7+)는 원본 값이다. 사용자가 나중에 실제 값으로 바꾼다.
  위치는 `src/features/about/model/about.constants.ts` 다.
- GitHub 링크는 아직 페이지 맨 위를 가리킨다(`src/config/site.ts`).
- 4번째 작업 카드는 썸네일이 없어 임시 이미지를 표시한다(`content/projects.ts`).
