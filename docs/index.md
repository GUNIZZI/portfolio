# 문서 안내

**이 저장소의 규칙 문서 전부다.** 코드를 건드리기 전에 이 표로 읽을 문서를 고른다.

문서는 하나만 둔다.
사람이 읽는 설명과 지켜야 할 규칙을 한 파일에 함께 적는다.
AI 전용 요약본을 따로 만들지 않는다.(Kozipsa `docs/index.md` 에서 가져옴, 2026-11-11 사용자 결정)

## 문서 규격

주제 하나에 파일 하나를 쓴다. 아래 항목으로 구성한다.

| 항목     | 내용                                                 |
| -------- | ---------------------------------------------------- |
| 원칙     | 선택이 필요할 때 판단 기준이 되는 몇 줄              |
| 본문     | 규칙과 그 이유                                       |
| 금지사항 | `금지` · `대신` · `근거` 3열 표                      |
| 미정리   | 실제 코드와 규칙이 아직 어긋난 곳과 그 개수          |
| 확인방법 | 규칙이 지켜지는지 보는 명령. 기대 출력을 함께 적는다 |

## 근거 표기

**규칙 문장에는 근거를 함께 적는다.** 근거는 3가지 중 하나다.

| 근거      | 표기                                        |
| --------- | ------------------------------------------- |
| 실제 코드 | 경로를 적는다(`src/style/tokens/motion.ts`) |
| 기존 문서 | 문서와 절을 적는다(`architecture.md` 3절)   |
| 사용자    | 정한 시점을 적는다(커밋 해시나 날짜)        |

Kozipsa 에서 가져온 규칙은 `Kozipsa <문서> 에서 가져옴` 으로 적는다.
Kozipsa 의 규칙을 가져오기로 한 것은 2026-11-11 사용자 결정이다.

**근거가 3가지 중 어디에도 없는 문장은 적지 않는다.** 일반적으로 맞는 말이어도 적지 않는다.
근거를 새로 만들어야 한다면 정책을 추가하는 것이다. 무엇을 왜 정해야 하는지 먼저 말하고
컨펌을 받은 뒤에 적는다.
