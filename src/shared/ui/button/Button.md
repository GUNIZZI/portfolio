# Button

버튼이다. `href` 를 주면 링크(`<a>`)로, 주지 않으면 `<button>` 으로 그린다.(`Button.tsx` 의 `OwnProps`)
링크는 페이지 안 이동과 `mailto:` 에, `<button>` 은 폼 제출과 동작에 쓴다.

| prop     | 값                                              | 기본     |
| -------- | ----------------------------------------------- | -------- |
| `intent` | `accent` · `brand` · `outline` · `outlineBrand` | `accent` |
| `size`   | `md`(높이 44) · `lg`(높이 48)                   | `lg`     |
| `href`   | 이동할 곳. 주면 링크, 없으면 `<button>`         |          |
| `effect` | `sweep`(연출) · `none`(색만 바로 바뀜)          | `sweep`  |
| `type`   | `<button>` 일 때만. `<button>` 의 `type` 그대로 | `button` |

아이콘은 자식으로 넣는다. 간격은 버튼에 정해져 있다.

```tsx
<Button href="#projects">
    View My Projects
    <Icon name="arrowRight" size={18} strokeWidth={2.2} />
</Button>
```

## hover · 포커스

마우스를 올리거나 키보드로 초점을 주면 세 가지가 함께 움직인다.(2026-11-16 사용자 결정. 이전의 색 전환만으로는 올린 것을 알기 어려웠다)

| 움직임                                            | 토큰                                                     |
| ------------------------------------------------- | -------------------------------------------------------- |
| 다른 색의 면이 왼쪽에서 밀려 들어와 덮는다        | `duration-fast` · `ease-move`                            |
| 버튼의 면이 오른쪽으로 12px 넓어진다              | `duration-fast` · `ease-move`                            |
| 맨 끝의 아이콘이 조금 늦게 따라 오른쪽으로 밀린다 | `duration-fast` · `ease-move`, 늦추기 `duration-instant` |

- 누르면 조금 눌린다. 떠오르는 움직임은 두지 않는다.(2026-11-16 사용자 결정)
- 넓어지는 것은 폭을 움직이지 않는다. 면을 처음부터 오른쪽으로 12px 더 길게 깔고 `clip-path` 로 가렸다가 드러낸다. 레이아웃을 다시 계산하지 않고 옆의 요소도 밀리지 않는다.(`docs/motion.md` 원칙 4)
- 동작 줄이기에서는 색만 바로 바뀌고 넓어지거나 밀리지 않는다.

| `intent`       | 평소        | 덮는 색과 글자                   |
| -------------- | ----------- | -------------------------------- |
| `accent`       | 연두 바탕   | `strong`(흰색) 바탕, 글자 그대로 |
| `brand`        | 보라 바탕   | `accent`(연두) 바탕, 어두운 글자 |
| `outline`      | 흰 테두리   | `strong` 바탕, 어두운 글자       |
| `outlineBrand` | 보라 테두리 | `brand`(보라) 바탕, 흰 글자      |

## 연출 없이 쓰기

`effect="none"` 을 주면 면이 넓어지거나 밀려 들어오지 않고, 누를 때도 눌리지 않는다. hover · 포커스 때 덮는 색과 글자색만 바로 바뀐다.(2026-11-17 사용자 결정)
관리 화면의 로그인 · 로그아웃 버튼이 쓴다.(`src/features/adminAuth/`)
면이 넓어지지 않아 버튼 오른쪽에 12px 을 비우지 않아도 된다.

## 비활성

`<button>` 에 `disabled` 를 주면 면이 `chip`, 글자가 `muted` 로 바뀌고 마우스에 반응하지 않는다. hover 연출도 멈춘다.(`Button.tsx`)
`accent` 로만 써 봤다. 테두리 변형의 비활성 모양은 정하지 않았다.

## 자주 하는 실수

- 화살표처럼 밀려야 하는 아이콘은 맨 끝에 둔다. 맨 끝의 아이콘만 움직인다.
- 버튼 오른쪽에 12px 의 빈 곳을 둔다. hover 때 면이 그만큼 넓어진다.
- 폼 제출에는 `href` 없이 `type="submit"` 을 준다. 기본값은 `button` 이라 주지 않으면 제출하지 않는다.(`Button.tsx`)

## 이 컴포넌트를 고칠 때

변형 이름과 높이를 바꾸면 위 표와 `docs/design.md` 1절의 쓰는 곳을 함께 고친다.
