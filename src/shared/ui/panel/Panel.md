# Panel

섹션을 묶는 큰 면이다. 반투명이고(`bg-panel-glass`) 뒤를 흐려(`backdrop-blur-sm`), 배경 낙서가 흐리게 비친다.(2026-11-12 사용자 결정)
모서리는 24px 이다.
작업·기술 묶음과 소개 섹션이 쓴다.

`<div>` 의 속성을 그대로 받는다. 안쪽 여백과 배치는 쓰는 쪽이 `className` 으로 정한다.

## 이 컴포넌트를 고칠 때

면의 단계는 `panel` › `card` › `chip` 이다. 패널만 반투명이고 카드와 칩은 불투명이다. 카드는 이 컴포넌트를 쓰지 않고 `bg-card` 를 직접 쓴다.
