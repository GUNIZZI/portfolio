# Icon

선으로 그린 24px 아이콘이다. 모양은 디자인 원본(`sample/`)의 SVG 그대로다.
`menu` · `close` 는 원본에 없어 같은 굵기와 끝 모양으로 더했다.(2026-11-12 사용자 결정, `docs/plan/home/README.md` 검토 필요 사항 18)

| prop          | 값                                   | 기본 |
| ------------- | ------------------------------------ | ---- |
| `name`        | `IconName`(`Icon.tsx` 의 `ICONS` 키) |      |
| `size`        | 한 변의 길이(px)                     | 24   |
| `strokeWidth` | 선 굵기                              | 1.8  |

색은 `currentColor` 다. 감싸는 요소의 글자색을 따른다.

## 자주 하는 실수

- 아이콘만 있는 링크에 이름을 빠뜨리지 않는다. 아이콘은 `aria-hidden` 이라, 감싸는 `<a>` 에 `aria-label` 을 단다.

## 이 컴포넌트를 고칠 때

새 아이콘은 `ICONS` 에 한 항목을 더한다. 파일을 따로 만들지 않는다.
