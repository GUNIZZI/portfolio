# comment-write

**이 스킬에는 규칙도 절차도 적지 않는다.**
규칙은 `docs/writing.md`, 절차는 `.claude/skills/doc-write/SKILL.md` 에 있다.
여기에는 문서 교정과 **다른 점만** 적는다.

대상은 `src/**` 와 루트 설정 파일의 `.ts` · `.tsx` · `.css` · `.mjs` 다.
`.md` 는 `/doc-write` 가 맡는다. 파일 종류로 갈린다.

## 0. 전제

- **`/comment-write` 호출로만 실행된다.** 평문 요청에는 호출해 달라고 한 줄로 안내한다.
- **인수로 받은 파일만 본다.** 여러 개를 받으면 파일 단위로 반복한다.
- **주석만 본다.** 코드와 식별자, 문자열 리터럴은 건드리지 않는다.
  주석을 고치다 코드에 손대지 않는다.
- **한글이 없는 주석은 건너뛴다.** 영어 주석과 `eslint-disable` 같은 지시 주석이 그렇다.

## 1. 규칙을 읽는다

`docs/writing.md` 를 읽는다. 요약하지 않는다.

**어느 조항이 주석에 걸리는지는 그 문서의 `원칙` 절 첫머리가 적어 둔다.**
조항이 늘면 그 목록도 함께 늘어나므로 여기에 번호를 옮겨 적지 않는다.

## 2. 대상을 읽는다

대상 파일 전체를 줄 번호와 함께 읽고, 주석 줄만 골라낸다.
문서 규격은 주석에 해당하지 않으므로 여기서는 보지 않는다.

## 3~5. 공통 절차를 따른다

`.claude/skills/doc-write/SKILL.md` 의 3 · 4 · 5 단계를 읽어서 그대로 따른다.
2갈래로 갈라 보고하고, 승인받은 줄만 치환하고, 새 규칙 후보를 제시하는 순서다.
절차를 이 파일에 옮겨 적지 않는다.

## 금지사항

| 금지                       | 대신                          | 근거                                         |
| -------------------------- | ----------------------------- | -------------------------------------------- |
| 규칙 조항을 이 파일에 적기 | `writing.md` 를 읽기          | 같은 내용이 2곳에 생긴다                     |
| 공통 절차를 이 파일에 적기 | `doc-write/SKILL.md` 를 읽기  | 한쪽을 고칠 때 다른 쪽이 뒤처진다            |
| 주석을 고치다 코드 고치기  | 주석 줄만 치환하기            | 코드 변경은 이 스킬의 일이 아니다            |
| 승인 없이 문장을 고치기    | 공통 절차 3단계에서 표로 묻기 | 루트 `CLAUDE.md` `# 규칙` 이 컨펌을 요구한다 |
| `.md` 를 이 스킬로 다루기  | `/doc-write` 를 호출하기      | 파일 종류로 갈린다                           |
| 커밋까지 진행하기          | `/commit` 을 호출하라고 안내  | 커밋은 커밋 스킬만 한다                      |
